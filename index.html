Backend-first, full-stack when it counts

I work primarily in ASP.NET Core, building APIs around Clean Architecture — Specification pattern, Generic Repository, Unit of Work — with EF Core and SQL Server underneath. Lately I've been deepening Redis-based caching for high-traffic endpoints like cart/basket flows.

On the frontend I use React when a project needs a full-stack hand, so I can ship a feature end-to-end without waiting on a handoff.
